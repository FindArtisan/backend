# FindArtisan API

FastAPI backend for **FindArtisan** — a solution that helps clients find skilled artisans nearby and request their services.

## Requirements

- Python 3.13
- [uv](https://docs.astral.sh/uv/) package manager

## Getting started

```bash
# Install dependencies (creates .venv automatically)
uv sync

# Run the development server
uv run uvicorn api.main:app --reload

# Or via the project script (development server on port 8000)
uv run find-artisan-api
```

The API is now available at:

- Swagger UI: <http://localhost:8000/docs>
- ReDoc: <http://localhost:8000/redoc>
- Health check: <http://localhost:8000/health>

## Configuration

Copy `.env.example` to `.env` and adjust values. Settings are loaded via pydantic-settings in
`api/core/config.py`. `DATABASE_URL` defaults to a local SQLite file for development;
point it at Postgres (`postgresql+asyncpg://...`) in production.

## Database models & migrations

The schema uses SQLAlchemy 2 (async) with Alembic migrations:

- `users` — one table for all users (clients and artisans), with a `role` field
- `artisan_profiles` — 1:1 with `users` (`user_id` FK, unique, `ON DELETE CASCADE`)
  holding artisan-specific attributes (trade category, bio, experience, pricing)

```bash
uv run alembic upgrade head                                  # apply migrations
uv run alembic downgrade -1                                  # revert last migration
uv run alembic revision --autogenerate -m "change summary"   # new migration from model changes
```

Always inspect autogenerated migrations before committing them.

## Testing & linting

```bash
uv run pytest -W error::DeprecationWarning # run tests (warning-free is the bar)
uv run ruff check . # lint
uv run ruff format . # format
```

## Project structure

```
src/api/
├── __init__.py
├── main.py                # FastAPI app factory + entry point
├── core/
│   ├── config.py          # Settings (pydantic-settings)
│   └── db.py              # Async engine, session factory, get_db dependency
├── models/
│   ├── base.py            # Declarative Base (naming convention) + TimestampMixin
│   ├── user.py            # User model (single accounts table, Role enum)
│   └── artisan_profile.py # ArtisanProfile model (1:1 with users via user_id FK)
└── routers/
    └── health.py          # /health endpoint
migrations/                # Alembic (async template)
tests/
└── test_health.py
```
